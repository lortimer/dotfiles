# Where to find Jetbrains files

[Look on the Jetbrains website](https://intellij-support.jetbrains.com/hc/en-us/articles/206544519-Directories-used-by-the-IDE-to-store-settings-caches-plugins-and-logs)

Keymaps have to go in the specified folder plus 'keymaps', so on my current MacOS, it's /Users/ryan/Library/Application Support/JetBrains/WebStorm2025.3/keymaps
